Writion is an in-progress Markdown editor app based on Apple's **Landmarks** sample project.

> ⚠️ This project is **not finished** yet.

## Project Status

- Base project: Apple sample **Landmarks**.
- Current stage: early branding and foundational changes.
- Development status: unfinished; features are still being iterated.

## Notes

- This repository started from the Landmarks sample and has been modified for Writion.
- The app is currently under active development.

## Acknowledgement

Original sample reference:
- [Landmarks: Building an app with Liquid Glass](https://developer.apple.com/documentation/swiftui/landmarks-building-an-app-with-liquid-glass)
